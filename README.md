# CartEye: Supermarket Checkout Automation

Automating supermarket checkout using computer vision for the Vista’26 Hackathon (IIT BHU).

## Project Structure
- `data/`: Dataset storage (raw and processed).
- `models/`: Weights and exported models.
- `notebooks/`: EDA and experimentation.
- `src/`: Core source code.
- `scripts/`: Utility scripts for training and inference.

## Setup Instructions
1. Create a virtual environment:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Mac/Linux
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
